# ПРОЕКТЫ ВЕНТПРОМ — панель в VS Code

Читает реестр проектов `PROJECTS.md` с указанного в настройках сервера по ssh (native Windows ssh, кириллица через base64),
разбирает блоки `## КОД — название` и раскладывает по группам: В РАБОТЕ / В ПЛАНЕ / НЕ РАЗМЕЧЕНО / ЗАКРЫТО.

Как определяется «в работе» (по порядку):
1. явная метка в блоке: `[в работе]` `[в плане]` `[закрыто]` `[пауза]` — главнее всего;
2. поле `- **Статус:**`: «закрыт» без «далее/осталось» → ЗАКРЫТО; «закрыт» + «далее» → В РАБОТЕ;
   «запланировано/в плане» → В ПЛАНЕ; иначе статус заполнен → В РАБОТЕ;
3. поля «Статус» нет: последняя дата в блоке свежее `activeDays` (30) → В РАБОТЕ, иначе НЕ РАЗМЕЧЕНО.
   Будущие даты (срок сертификата, оплата домена) за активность не считаются.

Кэш и офлайн: последняя удачная копия лежит в globalStorage расширения; если сервер не ответил
(например, VPN перехватывает локальную сеть), панель показывает копию и дату сверху, а не пустоту.

Настройки — `ventpromProjects.*`: host (обязательно, дефолта нет), remotePath, sshExe, refreshMinutes, activeDays, onlyInWork, timeoutSeconds.
